# Forks

Each folder here is a git submodule: a link to one of our forks, pinned to the exact commit that runs on the machine. On GitHub, clicking a folder opens the fork at that commit. Our commits are also kept here as plain patch files in [`../patches/`](../patches), and the story behind each one is in [`../docs/forks.md`](../docs/forks.md).

To get the presentation and every fork at once: `git clone --recurse-submodules https://github.com/samucarre/waybian`. `linux-aurora` is marked `update = none` in `.gitmodules`, so that skips a kernel tree of several gigabytes; fetch it on purpose with `git submodule update --init --checkout forks/linux-aurora`. The kernel that actually runs is built from a private fork (local patches, configurations and install scripts) that is not included.
